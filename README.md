# 🛡️ AI Code Guardian // AI

**FIND FIXES | FIX CODE | BUILD SAFER SOFTWARE**

AI Code Guardian is a portable, AI-powered local application designed to scan Python codebases for security vulnerabilities, code quality issues, and outdated dependencies. It features a stunning dark-themed dashboard and explains complex code errors in plain English using Groq's LLaMA-3 AI.

## ✨ Features
- **Multi-Scanner Engine:** Integrates Bandit, Pylint, Gitleaks, and OSV-Scanner.
- **AI Explanation:** Explains vulnerabilities line-by-line using Groq (LLaMA-3).
- **Multiple Upload Options:** Scan via GitHub Repository link, .zip file, or local Folder.
- **Futuristic Dashboard:** Highly responsive dark-mode UI built with TailwindCSS.
- **100% Private & Local:** Code never leaves your machine.

## 🛠️ Tech Stack
- **Frontend:** HTML5, TailwindCSS, Vanilla JS
- **Backend:** Python, FastAPI, Uvicorn
- **AI Engine:** Groq API (LLaMA 3.1)

## 🚀 Installation
1. Clone the repo: git clone https://github.com/qasimaliaiengineer77-stack/AI-Code-Guardian.git 
2. Run 1_Install_App.bat to set up the environment.
3. Rename .env.example to .env and add your Groq API key.
4. Double-click CodeGuardian.AI on your Desktop to run!
